# Quantum RSS Radar — Data Archive

This branch stores auto-generated daily pipeline outputs:
- `data/all/data_YYYY-MM-DD_HHMMSS.jsonl` — all papers (one JSON per line)
- `data/reports/report_YYYY-MM-DD_HHMMSS.md` — human-readable Markdown report

**Retention policy:** files older than 6 months are automatically removed.
**Source code** is on the `master` branch.
