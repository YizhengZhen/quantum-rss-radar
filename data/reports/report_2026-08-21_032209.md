### TL;DR

Proposes a three-tier multi-agent architecture for V2X security that treats the 100-millisecond Basic Safety Message cycle as a hard requirement, with vehicle-level, edge, and cloud tiers.

### Motivation

Existing intrusion detection systems are not designed to handle the coupling between safety and security in connected vehicles, and they are blind to fleet-wide attack patterns and the tension between dropping suspicious messages and dropping legitimate emergency alerts.

### Method

Three-tier architecture: onboard agent classifies each message into Accept, Drop, Quarantine, or Escalate within 10ms; edge agent with 50ms budget fuses threat assessments; cloud tier uses Byzantine fault-tolerant federated learning.

### Result

The architecture assigns standards-grounded latency budgets to all three tiers and treats safety-security conflict resolution as a first-class design constraint.

### Conclusion

Open problems include adversarial poisoning at the edge and lack of regulatory frameworks for autonomous security response.
