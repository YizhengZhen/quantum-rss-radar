### TL;DR

Introduces ACLE-MCP, a capability-lease architecture that binds OAuth authorization to provider-side workload attestation to close the post-authorization execution trust gap in remote LLM tool use.

### Motivation

OAuth authorization does not guarantee that tool calls are executed by the intended workload, leaving a trust gap where execution could shift to substituted or stale components.

### Method

ACLE-MCP issues short-lived capability leases bound to workload attestation, operation constraints, and freshness, enforced by a provider-side Execution Gate prior to protected tool logic.

### Result

Prototype evaluation shows that ACLE-MCP blocks all evaluated attack families while preserving benign tasks, with a 25.7% increase in request-level pooled p95 latency for normal calls.

### Conclusion

Invocation-time binding between call authority and current workload state is a practical complement to OAuth for remote tool use.

*Keywords: capability leases, execution-time trust, LLM tool use, OAuth, attestation*

## 142. Card-Based Computation In The Virtual Player Simulation Model

- **Score**: 0.0 / 10  |  **Recommended**: ❌ No

- **Direction**: General / Other
- **Published**: 2026-09-03
- **Authors**: Suthee Ruangwises
- **Link**: [https://arxiv.org/abs/2609.02716](https://arxiv.org/abs/2609.02716)
- **Tags**: `card-based cryptography`  `player simulation`  `secure computation`  `card games`  `protocols`

### TL;DR

The paper proposes generic card-based computation protocols (Play-Minimum and Sorting) for the virtual player simulation model, enabling secure operations on a virtual player's hand in card games.

### Motivation

To advance the emerging field of player simulation in card-based cryptography by providing reusable primitives for games with ranked cards, addressing constraints like preserving the game state and hand.

### Method

The authors design two protocols: Play-Minimum for securely selecting and playing the minimum-value card (or maximum by symmetry) when all values are distinct, and Sorting for arranging the hand in nondecreasing order even with ties.

### Result

The protocols constitute generic computational primitives independent of specific card games, applicable to any game with a publicly known ranking of cards.

### Conclusion

This work contributes to understanding the computational capabilities of the virtual player simulation model and provides foundational tools for future card-based cryptographic protocols.

*Keywords: card-based cryptography, player simulation, secure computation, card games, protocols*
