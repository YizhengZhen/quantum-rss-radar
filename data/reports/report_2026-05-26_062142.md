### TL;DR

DateSAT is a framework for solving satisfiability constraints involving dates and calendar periods using SMT reductions.

### Motivation

Dates and calendar periods are common in software and data analysis, but existing tools lack native support for calendrical arithmetic, leading to errors.

### Method

The paper formalizes an input language and semantics for date/period arithmetic, and presents five strategies for reducing DateSAT constraints to SMT formulas over integers, implemented with Z3.

### Result

A dataset of 450 DateSAT constraints was curated and used to evaluate solver performance across the five strategies.

### Conclusion

DateSAT provides the first dedicated framework for date-related constraint solving, with potential applications in program analysis and verification.
